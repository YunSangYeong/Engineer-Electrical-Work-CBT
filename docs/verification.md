- 기존 첫 100개 객체(ID·본문·보기·정답·해설·출처 메타데이터)와 전체 내용을 보존했다. 고정 SHA-256 테스트로 이를 확인했다.

- 각 템플릿의 조건·수식·단위·해설을 내부 검토하고 별도 TypeScript 계산/역산 경로로 수치·단위·정답 보기·반올림·동치 보기 여부를 검증했다. [전체 템플릿별 검수 기록](bank-review.md) 참조.
- 현재 단위 테스트 **1,009개 통과**. 기존 ID 보존, 과목별200, 유형별20조건, 전체1,000개 순회, 시험 추출50유형·100문항, 과락/평균/시간/복원/가져오기 경계를 포함한다.
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e` 종료 0: PC·모바일 브라우저 28개 통과(52.9초), 실패/skip 0. 작은 높이·가로 메뉴의 실제 휠/터치와 Space·저장·등록 회귀 포함. 실기기 미검증.

- 공식 출제기준·규정값 대조·전문가 검수 미완료 상태는 유지한다. 법규 과목은 안전 측정·계산 기초이며 최신 KEC 법정 기준이나 적합 판정 문항을 제공하지 않는다.
