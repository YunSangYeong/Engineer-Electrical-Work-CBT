# 1,000문항 템플릿 검수 내역

기존 100개와 신규 900개를 합친 자체 제작 계산 조건 변형이다. 아래 50개 템플릿 각각에 서로 다른 조건 20개가 있다. 일부 템플릿은 수학적으로 같은 수식을 서로 다른 전기 맥락에 사용한다. ID·정규화 본문/보기 중복은 별도로 검사하며 같은 템플릿 안의 의미상 유사성은 의도한 숫자 변형으로 공개한다.

## 검수 범위

- 조건의 명시성, 전기량·단위·식·해설의 논리와 적용 한계를 템플릿 단위로 내부 검토했다. 문항별 보기 수치·단위·정답 번호·중복·반올림을 별도 TypeScript 경로로 검사한다.
- 입력은 양수·유효 범위이며 전력/효율/슬립/피드백 등의 전제 조건을 확인했다. 반올림 문항은 소수 둘째 자리 기준이며 오차 허용 한계는 0.005000001이다. 보기 간격이 1이어서 반올림에 의한 정답/오답 보기 충돌은 없다.
- 온도·비저항·계기·회로는 문항에 적힌 이상화 조건이다. 인체 저항이나 측정 전류 등 가정값을 공식 규정값으로 표시하지 않았다.
- AI 일반 지식에 근거한 자체 작성이며 읽지 않은 외부 자료는 인용하지 않았다. 공식 출제기준/법규 대조·교재 확인·독립 전문가 검수는 미완료다.
- 과목당 200개이지만 법규 과목은 최신 법정 수치 대신 안전 측정의 기초 계산만 다룬다. 전체 출제범위/시험 준비 완성도를 문항 수로 보장하지 않는다.
