## 기능

실전 모의시험, 랜덤 즉시 채점, 과목 선택, 절대 종료 시각·자동 제출·새로고침 복원, 답안 수정, 결과·과목별 채점·과락, 오답 복습·정답 시 해제, 북마크, 실제 학습 통계, JSON 기록 백업·확인 후 초기화, JSON/CSV 문항 등록·중복 제거·검증 대기·근거 입력 후 로컬 승인·검색·내보내기를 제공합니다.

학습 기준/연도 선택 메뉴가 없습니다. 실전은 응답 후, 랜덤은 채점 후 Space로 다음 문제로 이동합니다. 마지막 실전 문제의 Space는 제출하지 않습니다. 입력 컨트롤·열린 메뉴·대화상자·반복 키를 보호합니다. 작은 높이·가로 화면의 모바일 메뉴는 독립 스크롤합니다. 비공식 표시는 사이드바/푸터에 두며 상단 상시 면책 배너는 없습니다. 실제 저장 손상·실패 경고는 유지합니다.

## 실제 문제은행: 1,000 / 목표 1,000, 부족 0

| 과목 | 내부 검수 등록 수 | 문항 템플릿 수 | 내용 |
|---|---:|---:|---|
| 전기응용 및 공사재료 | 200 | 10 | 조명·전열·전지·도체·열팽창 |
| 전력공학 | 200 | 10 | 선로 손실·전압 강하·3상 전력·전력 관리·단위법 |
| 전기기기 | 200 | 10 | 유도기·변압기·직류기·효율·토크 |
| 회로이론 및 제어공학 | 200 | 10 | 직류·교류·저장 소자·과도현상·피드백 |
| 전기설비기술기준 | 200 | 10 | 안전 측정·보호도체·절연·접지·고장 루프 계산 기초 |

- 원문 기출 **0**, 복원 **0**, 자체 제작 **1,000**. 전부 숫자 조건 변형입니다.
- **50개 문항 템플릿 × 20조건 = 1,000개**. 일부 템플릿은 다른 과목·맥락에서 같은 수식을 공유합니다. 독립 개념 또는 기출 1,000개를 확보했다는 의미가 아닙니다. 별도 비계산 문항 0개.
- 기본 JSON의 검수 대기 0개, ID/정규화 본문·보기 중복 0개. 개인 로컬 등록분은 포함하지 않습니다. 기존 100개 ID·문제·정답·해설·메타데이터를 그대로 보존했습니다.
- 50개 템플릿의 조건·수식·단위·해설을 내부 검토하고 생성기와 분리한 TypeScript 검증 경로로 1,000개 문항의 수치·단위·정답 보기·반올림을 확인했습니다. [템플릿별 검수 내역](docs/bank-review.md)에 근거와 범위를 기록했습니다.
- AI 일반 지식 기반 자체 제작이며 외부 전문가 검수·공식 출제기준 대조 완료를 뜻하지 않습니다. 기초 계산 중심이며 전체 공식 범위와 실제 난이도를 대표하지 않습니다. **법규 과목 200개는 안전 관련 계산 기초이며 최신 법정 기준값·KEC 적합 판정 문항을 확보한 것은 아닙니다.**
- 시험은 과목별 10개 템플릿을 각각 한 번 우선 추출한 뒤 나머지 10개를 서로 다른 ID로 보충합니다. 한 회 총 100문항입니다. 과목별 최소 한 번씩 모든 템플릿이 포함되지만 같은 유형이 여러 번 나올 수 있습니다.
- 출제 연도·회차는 모두 null. 저장소 URL은 작성 위치일 뿐 외부 정답 근거가 아닙니다. 새 자료는 CC BY 4.0으로 표시하며 민간 사이트 문제를 복제하지 않았습니다.
- 생성: `python3 scripts/generate_bank.py` 및 `scripts/expanded_bank.py`. 결정적 ID/순서, 난수 미사용. 재생성 SHA-256: `7a0841cb2913a3f3c67f568561597a28aeadddf10aae5f3b6d192a339cdd9b62`.

## 개발·검증

Node 24.19.0(`.node-version`, engines >=22.12.0). 기존 checkout을 사용하며 worktree가 필요하지 않습니다.

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

시스템 Chromium을 쓸 때는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`를 사용합니다. 개발 서버·브라우저 실행에는 환경의 소켓/프로세스 허용이 필요합니다. 상세 실제 결과는 [검증 기록](docs/verification.md)을 참조하세요.

## 저장·자료 등록
