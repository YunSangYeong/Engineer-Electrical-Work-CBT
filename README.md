## 기능

실전 모의시험, 랜덤 즉시 채점, 과목 선택, 절대 종료 시각·자동 제출·새로고침 복원, 답안 수정, 결과·과목별 채점·과락, 오답 복습·정답 시 해제, 북마크, 실제 학습 통계, JSON 기록 백업·확인 후 초기화, JSON/CSV 문항 등록·중복 제거·검증 대기·근거 입력 후 로컬 승인·검색·내보내기를 제공합니다.

학습 기준/연도 선택 메뉴가 없습니다. 실전은 응답 후, 랜덤은 채점 후 Space로 다음 문제로 이동합니다. 마지막 실전 문제의 Space는 제출하지 않습니다. 입력 컨트롤·열린 메뉴·대화상자·반복 키를 보호합니다. 작은 높이·가로 화면의 모바일 메뉴는 독립 스크롤합니다. 비공식 표시는 사이드바/푸터에 두며 상단 상시 면책 배너는 없습니다. 실제 저장 손상·실패 경고는 유지합니다.

`src/profile.ts`에 잠정 학습 설정을 모았습니다. **공식 시험 재현 검증 완료를 뜻하지 않습니다.**

2026-11-01 요청은 `curl: (56) CONNECT tunnel failed, response 403`으로 차단됐습니다. 이 페이지 본문, 최신 출제기준 및 저작물 이용 조건을 읽지 못했습니다. 위 과목·문항·시간·합격·과락은 일반 지식을 바탕으로 한 잠정 설정입니다. 최신 규정 수치를 검증했다고 주장하지 않습니다. 공식 원문과 재배포 조건 확인 전 기출·복원 문항을 등록하지 않았습니다.

## 실제 문제은행: 100 / 목표 1,000, 부족 900

| 과목 | 내부 검수 등록 수 | 독립 계산 유형 |
|---|---:|---|
| 전기응용 및 공사재료 | 20 | 작업면 입사 광속으로 평균 조도 |
| 전력공학 | 20 | 도체 한 가닥의 저항 손실 |
| 전기기기 | 20 | 유도전동기 슬립 |
| 회로이론 및 제어공학 | 20 | 직렬 RL 임피던스 크기 |
| 전기설비기술기준 | 20 | 보호도체 측정의 옴의 법칙 기초(법규 적합 판정 아님) |

- 원문 기출 **0**, 복원 **0**, 자체 제작 **100**. 자체 제작 100개 전부 계산 조건 변형입니다.
- **5유형 × 20조건 = 100개**이며 독립 개념 100개나 기출 100개로 해석하면 안 됩니다. 변형을 제외한 별도 비계산 문항 0개.
- 기본 JSON 중 검수 대기 0개, ID/정규화 본문·보기 중복 0개. 개인 로컬 등록분은 위 수에 포함하지 않습니다.
- 템플릿의 조건·수식·단위·해설을 내부 검토하고 각 문항 정답을 생성기와 별도의 TypeScript 역산 경로로 검증했습니다. AI 일반 지식 기반 자체 제작이며 외부 전문가 검수·공식 출제기준 대조·개별 독립 개념 검수 완료를 뜻하지 않습니다.
- 전체 난이도는 기초이며 공사재료·제어공학·법규 등 공식 전체 범위를 대표하지 않습니다. 특히 법규 과목은 적합 기준·최신 KEC 수치를 제공하지 않습니다. **검수 완료 1,000문항 표준은 미충족**입니다.
- 현재 은행은 정확히 한 시험 분량이므로 실전 시험마다 같은 100개 ID의 순서가 바뀝니다. 각 과목 유형이 하나여서 유형당 1개 우선 추출 뒤 나머지 19조건을 보충합니다. 문항 수 확대가 필요합니다.
- 출제 연도·회차는 모두 null. 저장소 URL은 작성 위치일 뿐 외부 정답 근거가 아닙니다. 새 자료는 CC BY 4.0으로 표시하며 민간 사이트 문제를 복제하지 않았습니다.
- 생성: `python3 scripts/generate_bank.py`. 결정적 ID/순서, 난수 미사용. 재생성 SHA-256: `98746fb57fb344904b4069b53c4e74a0ed6fc26a9a49a5d4e547bc8204b7346b`.

## 개발·검증

Node 24.19.0(`.node-version`, engines >=22.12.0). 기존 checkout을 사용하며 worktree가 필요하지 않습니다.

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

시스템 Chromium을 쓸 때는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`를 사용합니다. 개발 서버·브라우저 실행에는 환경의 소켓/프로세스 허용이 필요합니다. 상세 실제 결과는 [검증 기록](docs/verification.md)을 참조하세요.

## 저장·자료 등록

localStorage namespace: `Engineer-Electrical-Work-CBT:v1`. 최근 응답 5,000개·시험 30회, 진행 시험·랜덤 세션·오답·북마크·로컬 문제 저장. 같은 브라우저/origin 기준이며 다른 기기와 자동 동기화하지 않습니다. 백업은 내보내기이며 백업 복원 UI는 없습니다. 초기화 시 기본 문제는 유지됩니다. 손상 원본을 자동 덮어쓰지 않습니다. iframe/시크릿/저장 공간 제한에서는 기록 저장이 차단될 수 있습니다.

문항 가져오기는 공용 은행 게시가 아닌 해당 브라우저의 로컬 등록입니다. 출처·권한·정답 검수 후 근거를 남겨 승인해야 학습에 포함됩니다.
